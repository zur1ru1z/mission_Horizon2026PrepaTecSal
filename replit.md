# Energy and Transformation I - Command Center

## Overview
A static HTML/CSS "mission control" themed landing page for a course/class called "Energy & Transformation I". It includes:
- `index.html` — landing page (Hangar/Home)
- `modules.html` — Class Modules page
- `badges.html` — Command Badges page
- `style.css` — shared styling

No backend, no build step, no package.json — plain static assets referencing Google Fonts, Font Awesome, and external GIFs via CDN links.

## Running the project
The "Start application" workflow serves the static files with `python3 -m http.server 5000`. This is the simplest way to preview the site on Replit's port 5000 webview.
